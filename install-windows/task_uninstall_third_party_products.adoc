= Active IQ Unified Manager のサードパーティ製品をアンインストールする
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Managerをアップグレードした後、PythonやMicrosoft Visual C++ 2013などのサードパーティ製品をアンインストールできます。これは任意です。



[[uninstall-python]]
== Pythonをアンインストールする

.手順
. *コントロールパネル*から*プログラム* > *プログラムと機能*を選択します。
. プログラムのリストからPythonを選択します。
. 「このプログラムをアンインストールする」を選択してください。Pythonのバージョン3.13.3以外はすべてアンインストールしてください。Pythonのバージョン3.13.3を保持していることを確認してください。




[[uninstall-microsoft-visual-c-2013]]
== Microsoft Visual C++ 2013 をアンインストールする

.手順
. *コントロールパネル*から*プログラム* > *プログラムと機能*を選択します。
. プログラムの一覧から *Microsoft Visual C++ 2013* を選択してください。
. 「このプログラムをアンインストールする」を選択してください。
