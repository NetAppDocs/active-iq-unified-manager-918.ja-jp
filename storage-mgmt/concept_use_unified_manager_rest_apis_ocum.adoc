= Active IQ Unified Manager REST API を使用する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Managerには、ストレージ環境の監視と管理に関する情報を表示するためのREST APIが用意されています。また、ポリシーに基づいてストレージ オブジェクトをプロビジョニングおよび管理できるAPIもあります。

Unified ManagerでサポートされるAPIゲートウェイを使用して、ONTAPのすべての管理対象クラスタに対してONTAP APIを実行することもできます。

Unified Manager REST API の詳細については、link:../api-automation/concept_get_started_with_um_apis.html["Active IQ Unified Manager REST APIでの作業の開始"]を参照してください。
