= Active IQ Unified Manager の「Fix It」ボタンと「Fix All」ボタンのオプションについて学ぶ
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
管理アクションページには、Unified Managerがイベントを通じて通知を受けた問題を修正するための*修正*または*すべて修正*ボタンが用意されています。

必要に応じて、ボタンをクリックして問題を修正することを推奨します。ただし、Unified Manager が推奨する方法で問題を解決するかどうか確信が持てない場合は、以下の操作を実行できます。

|===
| 希望する処理 | *アクション* 


 a| 
特定されたすべてのオブジェクトについて、Unified Managerで問題を修正する。
 a| 
*Fix All*ボタンをクリックします。



 a| 
特定されたどのオブジェクトについても現時点では問題を修正せず、再度イベントが生成されるまでこの管理操作を非表示にする。
 a| 
下向き矢印をクリックし、*すべて閉じる*をクリックします。



 a| 
特定されたオブジェクトの一部についてのみ、問題を修正する。
 a| 
管理アクションの名前をクリックするとリストが展開され、個々の*Fix It*アクションがすべて表示されます。その後、個々の管理アクションを修正または解除する手順に従ってください。

|===
|===
| 希望する処理 | アクション 


 a| 
Unified Manager で問題を修正します。
 a| 
「Fix It」ボタンをクリックしてください。



 a| 
現時点では問題を修正せず、再度イベントが生成されるまでこの管理操作を非表示にする。
 a| 
下向き矢印をクリックし、*Dismiss* をクリックしてください。



 a| 
問題について詳しく確認するために、このイベントの詳細を表示する。
 a| 
* *Fix It*ボタンをクリックすると、ダイアログボックスに修正内容が表示されますので、内容をご確認ください。
* 下向き矢印をクリックし、*イベント詳細を表示*をクリックして、イベント詳細ページを表示します。


問題を解決したい場合は、表示されたいずれかのページから*Fix It*をクリックしてください。



 a| 
問題について詳しく確認するために、このストレージ オブジェクトの詳細を表示する。
 a| 
ストレージオブジェクトの名前をクリックすると、パフォーマンスエクスプローラーまたはヘルス詳細ページに詳細が表示されます。

|===
修正は、次の15分間に実施される構成ポーリングで反映されることもあれば、構成の変更が検証されてイベントが廃止状態になるまでに何時間もかかることもあります。

完了済みまたは進行中の管理アクションの一覧を表示するには、フィルターアイコンをクリックして *完了* または *進行中* を選択します。

Fix All操作は順番に実行されるため、*進行中*パネルを表示すると、一部のオブジェクトはステータスが*進行中*と表示されますが、他のオブジェクトはステータスが*スケジュール済み*と表示されます。つまり、それらはまだ実装待ちの状態です。
