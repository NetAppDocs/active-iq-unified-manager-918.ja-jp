= Active IQ Unified Manager でワークロードにポリシーを割り当てる
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
[すべてのワークロード]ページから、さまざまなナビゲーション オプションを使用して、ストレージ効率化ポリシー（SEP）とパフォーマンス サービス レベル（PSL）をストレージ ワークロードに割り当てることができます。



[[assign-policies-to-a-single-workload]]
== 単一のワークロードにポリシーを割り当てる

単一のワークロードにPSL、SEP、またはその両方を割り当てることができます。次の手順を実行します。

. ワークロードを選択します。
. 行の横にある編集アイコンをクリックし、次に*編集*をクリックします。
+
「割り当てられたパフォーマンスサービスレベル」と「ストレージ効率ポリシー」のフィールドが有効になっています。

. 必要なPSL、SEP、またはその両方を選択します。
. チェック マーク アイコンをクリックして変更を適用します。


[NOTE]
====
ワークロードを選択し、*その他の操作*をクリックしてポリシーを割り当てることもできます。

====


[[assign-policies-to-multiple-storage-workloads]]
== 複数のストレージワークロードにポリシーを割り当てる

複数のストレージ ワークロードにまとめてPSLまたはSEPを割り当てることができます。次の手順を実行します。

. ポリシーを割り当てるワークロードのチェック ボックスをオンにするか、データセンター内のすべてのワークロードを選択します。
. *その他の操作*をクリックします。
. PSLを割り当てるには、*パフォーマンスサービスレベルの割り当て*を選択します。SEPを割り当てるには、*ストレージ効率化ポリシーの割り当て*を選択します。ポリシーを選択するためのポップアップが表示されます。
. 適切なポリシーを選択し、*Apply*をクリックします。ポリシーが割り当てられているワークロードの数が表示されます。ポリシーが割り当てられていないワークロードも、その理由とともに一覧表示されます。
+
[NOTE]
====
ワークロードに対してポリシーを一括適用するには、選択したワークロードの数によっては時間がかかる場合があります。「バックグラウンドで実行」ボタンをクリックすると、操作がバックグラウンドで実行されている間、他の作業を続けることができます。一括割り当てが完了すると、完了状況を確認できます。複数のワークロードにPSLを適用する場合、前の一括割り当てジョブが実行中は、別のリクエストをトリガーすることはできません。

====




[[assign-system-recommended-psls-to-workloads]]
== ワークロードにシステム推奨のPSLを割り当てる

システム推奨PSLは、データセンター内のPSLが割り当てられていないストレージ ワークロード、または割り当てられたPSLがシステムの推奨事項と一致しないストレージ ワークロードに割り当てることができます。この機能を使用するには、「システム推奨PSLを割り当てる」ボタンをクリックしてください。特定のワークロードを選択する必要はありません。

この推奨事項はシステム分析によって内部的に決定され、IOPSやその他のパラメータが利用可能なPSLの定義と一致しないワークロードについてはスキップされます。 `Waiting for I/O`およびLearningステータスのストレージワークロードも除外されます。

[NOTE]
====
Unified Managerは、ワークロード名の中に特定のキーワードを探し出し、システム分析を上書きして、ワークロードに対して別のPSLを推奨します。ワークロード名に「`ora`」という文字が含まれている場合は、**Extreme Performance**PSLが推奨されます。ワークロード名に「`vm`」という文字が含まれている場合は、**Performance**PSLが推奨されます。

====
