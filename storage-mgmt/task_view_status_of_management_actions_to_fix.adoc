= Active IQ Unified Manager で修正する管理アクションのステータスを表示する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
管理アクションページでは、修正対象として選択したすべての管理アクションのステータスを確認できます。ほとんどのアクションは、Unified ManagerがクラスタにONTAPコマンドを送信したあと、かなり早く*Completed*と表示されます。ただし、ボリュームの移動など、一部の操作には時間がかかる場合があります。

[管理操作]ページでは、次の3つのフィルタを使用できます。

* *完了*には、正常に完了した管理アクションと失敗した管理アクションの両方が表示されます。*失敗*したアクションには失敗の理由が表示されるため、手動で問題に対処できます。
* *進行中*には、実装中の管理アクションと、実装がスケジュールされている管理アクションの両方が表示されます。
* 「推奨」には、監視対象のすべてのクラスターに対して現在有効になっているすべての管理アクションが表示されます。


.手順
. 左側のナビゲーションペインの*管理アクション*をクリックします。または、*ダッシュボード*の*管理アクション*パネルの上部にあるimage:../media/more_icon.gif["その他のアイコン"]をクリックし、表示するビューを選択します。
+
[管理操作]ページが表示されます。

. *概要*フィールドの管理アクションの横にあるキャレットアイコンをクリックすると、問題の詳細と、問題の解決に使用されるコマンドを確認できます。
. *失敗*したアクションを表示するには、*完了*ビューの*ステータス*列で並べ替えます。同じ目的で*フィルター*ツールを使用することもできます。
. 失敗した管理アクションに関する詳細情報を表示する場合、または推奨される管理アクションを修正する場合は、管理アクションの横にあるキャレットアイコンをクリックして展開された領域から*イベントの詳細を表示*をクリックします。そのページには*修正する*ボタンがあります。
