= Active IQ Unified Manager でジョブを監視する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
[ジョブ]ページでは、ジョブ ステータスを監視できるほか、ジョブのプロパティ（ストレージ サービス タイプ、状態、送信時刻、完了時刻など）を表示してジョブが正常に完了したかどうかを確認できます。

.開始する前に
アプリケーション管理者またはストレージ管理者のロールが必要です。

.手順
. 左側のナビゲーションペインで、*Protection* > *Jobs* をクリックします。
+
[ジョブ]ページが表示されます。

. *State* 列を参照して、現在実行中のジョブの状態を確認してください。
. 特定のジョブに関する詳細を表示する場合は、そのジョブ名をクリックします。
+
[ジョブの詳細]ページが表示されます。
