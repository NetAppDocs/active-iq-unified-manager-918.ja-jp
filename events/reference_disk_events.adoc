= Active IQ Unified Manager のディスクイベントについて
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ディスクのイベントは、ディスクのステータス情報を提供します。これにより、潜在的な問題を監視できます。影響範囲別にイベントがまとめられ、イベント名とトラップ名、影響レベル、ソース タイプ、および重大度が表示されます。
