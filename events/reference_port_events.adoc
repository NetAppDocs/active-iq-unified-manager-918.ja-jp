= Active IQ Unified Manager のポートイベントについて
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ポート イベントは、クラスタ ポートのステータスを提供して、ポートでの変更や問題（ポートがダウンしているかどうかなど）を監視できるようにします。



[[impact-area-availability]]
== 影響範囲：可用性

|===
| イベント名（トラップ名） | 影響レベル | ソース タイプ | 重大度 


 a| 
ポート ステータス - 停止（ocumEvtPortStatusDown）
 a| 
インシデント
 a| 
ノード
 a| 
重大

|===
