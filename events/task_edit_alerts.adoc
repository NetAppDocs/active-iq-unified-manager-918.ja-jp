= Active IQ Unified Manager でアラートを編集する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
関連付けられているリソース、イベント、受信者、通知オプション、通知頻度、関連付けられているスクリプトなど、アラートのプロパティを編集することができます。

.開始する前に
アプリケーション管理者のロールが必要です。

.手順
. 左側のナビゲーション ペインで、*ストレージ管理* > *アラート設定* をクリックします。
. 「Alert Setup」ページで、編集するアラートを選択し、「Edit」をクリックします。
. 「アラートの編集」ダイアログボックスで、必要に応じて名前、リソース、イベント、アクションの各セクションを編集します。
+
アラートに関連付けられているスクリプトについては、変更と削除が可能です。

. *保存*をクリックします。
