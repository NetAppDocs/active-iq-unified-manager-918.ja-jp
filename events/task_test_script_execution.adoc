= Active IQ Unified Manager でのテストスクリプトの実行
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージ オブジェクトに対してアラートが生成されたときにスクリプトが正しく実行されるかどうかを確認することができます。

.開始する前に
* アプリケーション管理者またはストレージ管理者のロールが必要です。
* サポートされるファイル形式のスクリプトをUnified Managerにアップロードしておく必要があります。


.手順
. 左側のナビゲーションペインで、*ストレージ管理* ＞ *スクリプト* をクリックします。
. 「スクリプト」ページにテストスクリプトを追加します。
. 左側のナビゲーション ペインで、*ストレージ管理* > *アラート設定* をクリックします。
. 「アラート設定」ページで、次のいずれかの操作を実行します。
+
|===
| 目的 | 操作 


 a| 
アラートを追加する
 a| 
.. *[追加]*をクリックします。
.. [操作]セクションで、テスト スクリプトにアラートを関連付けます。




 a| 
アラートを編集する
 a| 
.. アラートを選択し、*編集*をクリックします。
.. [操作]セクションで、テスト スクリプトにアラートを関連付けます。


|===
. *保存*をクリックします。
. 「Alert Setup」ページで、追加または変更したアラートを選択し、「Test」をクリックします。
+
「-test」引数を指定してスクリプトが実行され、アラートの作成時に指定したEメール アドレスに通知アラートが送信されます。
