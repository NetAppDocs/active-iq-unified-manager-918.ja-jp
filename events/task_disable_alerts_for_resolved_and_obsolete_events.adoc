= Active IQ Unified Manager で解決済みおよび廃止されたイベントのアラートを無効にする
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
アラートを送信するように設定したすべてのイベントについて、それらのイベントが「新規」、「解決済み」、「廃止済み」というすべての状態を遷移したときにアラートメッセージが送信されます。イベントが解決済みまたは廃止済み状態に移行した際にアラートを受信したくない場合は、グローバル設定を構成してこれらのアラートを抑制することができます。

.開始する前に
アプリケーション管理者またはストレージ管理者のロールが必要です。

デフォルトでは、イベントが解決済み / 廃止状態に移行する際にアラートは送信されません。

.手順
. 左側のナビゲーション ペインで、*ストレージ管理* > *アラート設定* をクリックします。
. 「Alert Setup」ページで、「Alerts for Resolved and Obsolete events」の横にあるスライダーコントロールを使用して、次のいずれかの操作を実行します。
+
|===
| 目的 | 操作 


 a| 
イベントが解決済みまたは廃止状態に移行したときのアラートの送信を停止する
 a| 
スライダを左に移動する



 a| 
イベントが解決済みまたは廃止状態に移行したときのアラートの送信を開始する
 a| 
スライダを右に移動する

|===
