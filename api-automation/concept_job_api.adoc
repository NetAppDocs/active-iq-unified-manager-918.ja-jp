= Active IQ Unified Manager でAPIを使用してジョブとシステムの詳細を表示する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
 `management-server`カテゴリの `jobs` APIを使用して、非同期操作の実行詳細を表示できます。 `management-server`カテゴリの `system` APIを使用すると、Active IQ Unified Manager環境のインスタンス詳細を表示できます。



[[view-jobs]]
== ジョブを表示

Active IQ Unified Managerでは、リソースの追加や変更などの処理は、同期および非同期のAPI呼び出しによって実行されます。非同期で実行予定の呼び出しは、その呼び出しに対して作成されたジョブ オブジェクトによって追跡できます。各 Job オブジェクトには、識別用の固有のキーがあります。各 Job オブジェクトは、ジョブの進捗状況にアクセスして追跡するための Job オブジェクト URI を返します。この API を使用すると、各実行の詳細を取得できます。

このAPIを使用すると、データセンターのすべてのジョブ オブジェクトを履歴データも含めて照会できます。デフォルトではすべてのジョブが照会され、Web UIおよびAPIインターフェイスからトリガーされた最新の20件のジョブの詳細が返されます。特定のジョブを表示するには組み込みのフィルタを使用してください。ジョブ キーを使用して特定のジョブの詳細を照会し、リソースに対して後続の一連の処理を実行することもできます。

[cols="4*"]
|===
| カテゴリ | HTTP動詞 | パス | 説明 


 a| 
management-server
 a| 
GET
 a| 
`/management-server/jobs`
 a| 
すべてのジョブの詳細を返します。ソート順序が指定されていない場合、最後に送信されたジョブ オブジェクトが最初に返されます。



 a| 
management-server
 a| 
GET
 a| 
`/management-server/jobs/\{key}`

ジョブ オブジェクトのジョブ キーを入力すると、そのジョブの詳細が表示されます。
 a| 
特定のジョブ オブジェクトの詳細を返します。

|===


[[view-system-details]]
== システムの詳細を表示

 `/management-server/system` APIを使用することで、Unified Manager環境のインスタンス固有の詳細情報を照会できます。APIは、システムにインストールされているUnified Managerのバージョン、UUID、ベンダー名、ホストOS、およびUnified Managerインスタンス上で実行されているサービスの名前、説明、ステータスなど、製品とサービスに関する情報を返します。

[cols="4*"]
|===
| カテゴリ | HTTP動詞 | パス | 説明 


 a| 
management-server
 a| 
GET
 a| 
`/management-server/system`
 a| 
このAPIの実行に必要な入力パラメータはありません。デフォルトで、現在のUnified Managerインスタンスのシステムの詳細が返されます。

|===
