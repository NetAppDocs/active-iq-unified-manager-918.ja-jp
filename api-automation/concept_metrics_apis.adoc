= Active IQ Unified Manager でAPIを使用してパフォーマンス指標を表示する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Managerは、データセンター内のクラスタおよびストレージオブジェクトのパフォーマンスデータを表示できる、 `/datacenter`カテゴリのAPIセットを提供します。これらのAPIは、クラスタ、ノード、LUN、ボリューム、アグリゲート、ストレージVM、FCインターフェイス、FCポート、イーサネットポート、IPインターフェイスなど、さまざまなストレージオブジェクトのパフォーマンスデータを取得します。

 `/metrics`および `/analytics` APIはパフォーマンス指標のさまざまなビューを提供し、これらを使用して、データセンター内の以下のストレージオブジェクトについてさまざまなレベルの詳細までドリルダウンできます：

* クラスタ
* ノード
* Storage VM
* アグリゲート
* ボリューム
* LUN
* FCインターフェイス
* FCポート
* イーサネット ポート数
* IPインターフェイス


以下の表は、取得されるパフォーマンスデータの詳細に関する、 `/metrics`および `/analytics` APIの比較を示しています。

[cols="2*"]
|===
| Metrics | Analytics 


 a| 
単一オブジェクトのパフォーマンス詳細。例えば、 `/datacenter/cluster/clusters/\{key}/metrics` APIでは、特定のクラスターのメトリクスを取得するために、パスパラメータとしてクラスターキーを入力する必要があります。
 a| 
データセンター内の同一タイプの複数オブジェクトに関するパフォーマンスの詳細。たとえば、 `/datacenter/cluster/clusters/analytics` APIは、データセンター内のすべてのクラスタの集合的なメトリクスを取得します。



 a| 
取得間隔パラメータに基づく、あるストレージ オブジェクトについてのパフォーマンス指標サンプル。
 a| 
特定のタイプのストレージ オブジェクトについての特定の期間（72時間以上）におけるパフォーマンス集計値。



 a| 
ノードやクラスタの詳細など、オブジェクトの基本的な詳細が取得される。
 a| 
個別の詳細は取得されない。



 a| 
単一のオブジェクトについて、読み取り、書き込み、合計などの分類で、一定期間におけるパフォーマンスの最小値、最大値、95パーセンタイル値、平均値の累積カウンタが取得される。
 a| 
同じタイプのすべてのオブジェクトについて、集計された値が1つ表示される。



 a| 
時間範囲とサンプルデータは、次のスケジュールに基づいています：データの時間範囲。例としては、1h、12h、1d、2d、3d、15d、1w、1m、2m、3m、6mなどが挙げられます。範囲が3日間（72 hr）を超える場合は1時間ごとのサンプルが取得され、それ以外の場合は5分ごとのサンプルが取得されます。各時間範囲の期間は以下のとおりです：

* 1h：過去1時間のメトリクスを5分間隔でサンプリング。
* 12h：過去12時間における5分間隔でサンプリングされた指標。
* 1d：直近1日間の指標を5分間隔でサンプリングしたもの。
* 2d：直近2日間の指標を5分間隔でサンプリングしたもの。
* 3d：直近3日間の指標を5分間隔でサンプリングしたもの。
* 15d：過去15日間の指標を1時間単位でサンプリングしたもの。
* 1w：直近1週間の指標を1時間単位でサンプリングしたもの。
* 1m：直近1か月間の指標を1時間単位でサンプリングしたもの。
* 2m：過去2か月間の指標を1時間単位でサンプリングしたもの。
* 3m：過去3か月間の指標を1時間単位でサンプリングしたもの。
* 6m：過去6か月間の指標を1時間単位でサンプリングしたもの。
+
選択可能な値：1h, 12h, 1d, 2d, 3d, 15d, 1w, 1m, 2m, 3m, 6m

+
デフォルト値：1時間


 a| 
72時間超。サンプルの計算期間はISO-8601標準形式で表されます。

|===

[[list-of-the-available-apis]]
== 使用可能なAPIの一覧

以下の表では、 `/metrics`および `/analytics` APIについて詳しく説明します。

[NOTE]
====
これらのAPIが返すIOPSとパフォーマンスメトリックはdouble型の値です（例： `100.53`）。これらの浮動小数点値をパイプ記号（|）とワイルドカード（*）でフィルタリングすることはサポートされていません。

====
[cols="3*"]
|===
| HTTP動詞 | パス | 説明 


 a| 
`GET`
 a| 
`/datacenter/cluster/clusters/\{key}/metrics`
 a| 
クラスタ キーの入力パラメータで指定したクラスタについて、パフォーマンス データ（サンプルとサマリ）を取得します。クラスタ キーやUUID、期間、IOPS、スループット、サンプル数などの情報が返されます。



 a| 
`GET`
 a| 
`/datacenter/cluster/clusters/analytics`
 a| 
データセンター内のすべてのクラスタについて、パフォーマンス指標の概要を取得します。必要な基準に基づいて結果をフィルタリングできます。IOPSやスループットの集計値、収集期間（時間数）などの情報が返されます。



 a| 
`GET`
 a| 
`/datacenter/cluster/nodes/\{key}/metrics`
 a| 
ノード キーの入力パラメータで指定したノードについて、パフォーマンス データ（サンプルとサマリ）を取得します。ノードのUUID、期間、IOPS、スループット、レイテンシ、パフォーマンスのサマリ、収集されたサンプル数、利用率などの情報が返されます。



 a| 
`GET`
 a| 
`/datacenter/cluster/nodes/analytics`
 a| 
データセンター内のすべてのノードについて、パフォーマンス指標の概要を取得します。必要な基準に基づいて結果をフィルタリングできます。ノードとクラスタのキー、IOPSやスループットの集計値、収集期間（時間数）などの情報が返されます。



 a| 
`GET`
 a| 
`/datacenter/storage/aggregates/\{key}/metrics`
 a| 
アグリゲート キーの入力パラメータで指定したアグリゲートについて、パフォーマンス データ（サンプルとサマリ）を取得します。期間、IOPS、レイテンシ、スループット、パフォーマンス容量のサマリ、各カウンタについて収集されたサンプル数、利用率などの情報が返されます。



 a| 
`GET`
 a| 
`/datacenter/storage/aggregates/analytics`
 a| 
データセンター内のすべてのアグリゲートについて、パフォーマンス指標の概要を取得します。必要な基準に基づいて結果をフィルタリングできます。アグリゲートとクラスタのキー、IOPSやスループットの集計値、収集期間（時間数）などの情報が返されます。



 a| 
`GET`
 a| 
`/datacenter/storage/luns/\{key}/metrics`

`/datacenter/storage/volumes/\{key}/metrics`
 a| 
LUNキーまたはボリューム（ファイル共有）キーの入力パラメータで指定したLUNまたはボリュームについて、パフォーマンス データ（サンプルとサマリ）を取得します。読み取り、書き込み、合計のIOPS、レイテンシ、スループットのサマリ（最小値、最大値、平均値）、各カウンタについて収集されたサンプル数などの情報が返されます。



 a| 
`GET`
 a| 
`/datacenter/storage/luns/analytics`

`/datacenter/storage/volumes/analytics`
 a| 
データセンター内のすべてのLUNまたはボリュームについて、パフォーマンス指標の概要を取得します。必要な基準に基づいて結果をフィルタリングできます。Storage VMとクラスタのキー、IOPSやスループットの集計値、収集期間（時間数）などの情報が返されます。



 a| 
`GET`
 a| 
`/datacenter/svm/svms/{key}/metrics`
 a| 
ストレージVMキーの入力パラメータで指定されたストレージVMのパフォーマンスデータ（サンプルと概要）を取得します。 `nvmf, fcp, iscsi,`や `nfs`など、サポートされている各プロトコルに基づくIOPSの概要、スループット、レイテンシ、および収集されたサンプル数が返されます。



 a| 
`GET`
 a| 
`/datacenter/svm/svms/analytics`
 a| 
データセンター内のすべてのStorage VMについて、パフォーマンス指標の概要を取得します。必要な基準に基づいて結果をフィルタリングできます。Storage VMのUUID、IOPS、レイテンシ、スループットの集計値、収集期間（時間数）などの情報が返されます。



 a| 
`GET`
 a| 
`/datacenter/network/ethernet/ports/{key}/metrics`
 a| 
ポート キーの入力パラメータで指定したイーサネット ポートについて、パフォーマンス指標を取得します。サポートされている範囲の間隔（期間）を指定すると、その期間におけるパフォーマンス値の最小値、最大値、平均値などの累積カウンタが返されます。



 a| 
`GET`
 a| 
`/datacenter/network/ethernet/ports/analytics`
 a| 
データセンター環境内のすべてのイーサネット ポートについて、パフォーマンス指標の概要を取得します。クラスタとノードのキーやUUID、スループット、収集期間、ポートの利用率などの情報が返されます。ポート キー、利用率、クラスタとノードの名前やUUIDなど、使用可能なパラメータで結果をフィルタリングできます。



 a| 
`GET`
 a| 
`/datacenter/network/fc/interfaces/{key}/metrics`
 a| 
インターフェイス キーの入力パラメータで指定したネットワークFCインターフェイスについて、パフォーマンス指標を取得します。サポートされている範囲の間隔（期間）を指定すると、その期間におけるパフォーマンス値の最小値、最大値、平均値などの累積カウンタが返されます。



 a| 
`GET`
 a| 
`/datacenter/network/fc/interfaces/analytics`
 a| 
データセンター環境内のすべてのイーサネット ポートについて、パフォーマンス指標の概要を取得します。クラスタとFCインターフェイスのキーやUUID、スループット、IOPS、レイテンシ、Storage VMなどの情報が返されます。クラスタとFCインターフェイスの名前やUUID、Storage VM、スループットなど、使用可能なパラメータで結果をフィルタリングできます。



 a| 
`GET`
 a| 
`/datacenter/network/fc/ports/{key}/metrics`
 a| 
ポート キーの入力パラメータで指定したFCポートについて、パフォーマンス指標を取得します。サポートされている範囲の間隔（期間）を指定すると、その期間におけるパフォーマンス値の最小値、最大値、平均値などの累積カウンタが返されます。



 a| 
`GET`
 a| 
`/datacenter/network/fc/ports/analytics`
 a| 
データセンター環境内のすべてのFCポートについて、パフォーマンス指標の概要を取得します。クラスタとノードのキーやUUID、スループット、収集期間、ポートの利用率などの情報が返されます。ポート キー、利用率、クラスタとノードの名前やUUIDなど、使用可能なパラメータで結果をフィルタリングできます。



 a| 
`GET`
 a| 
`/datacenter/network/ip/interfaces/{key}/metrics`
 a| 
インターフェイス キーの入力パラメータで指定したネットワークIPインターフェイスについて、パフォーマンス指標を取得します。サポートされている範囲の間隔（期間）を指定すると、サンプル数、累積カウンタ、スループット、送受信パケット数などの情報が返されます。



 a| 
`GET`
 a| 
`/datacenter/network/ip/interfaces/analytics`
 a| 
データセンター環境内のすべてのネットワークIPインターフェイスについて、パフォーマンス指標の概要を取得します。クラスタとIPインターフェイスのキーやUUID、スループット、IOPS、レイテンシなどの情報が返されます。クラスタとIPインターフェイスの名前やUUID、IOPS、レイテンシ、スループットなど、使用可能なパラメータで結果をフィルタリングできます。
