= Active IQ Unified Manager でバックアップとリストア操作を管理する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Managerのバックアップを作成し、システム障害やデータ損失が発生した場合に、リストア機能を使用して同じ（ローカル）システムまたは新しい（リモート）システムにバックアップをリストアできます。

Unified Managerをインストールしたオペレーティング システム、および管理対象のクラスタとノードの数に応じて、バックアップとリストアの方法は3種類あります。
