= Active IQ Unified Manager で注釈ルールを削除する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
不要になったアノテーション ルールは、Active IQ Unified Managerから削除できます。

.開始する前に
アプリケーション管理者またはストレージ管理者のロールが必要です。

アノテーション ルールを削除すると、アノテーションの関連付けが解除されてストレージ オブジェクトから削除されます。

.手順
. 左側のナビゲーションペインで、*ストレージ管理* ＞ *注釈* をクリックします。
. 「Annotation Rules」タブで、削除する注釈ルールを選択し、「Delete」をクリックします。
. 「警告」ダイアログボックスで、「はい」をクリックして削除を確定します。
