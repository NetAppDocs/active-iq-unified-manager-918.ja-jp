= Active IQ Unified Manager でグループルールを編集する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
グループ ルールを編集して条件グループおよび条件グループに含まれる条件を変更することで、特定のグループに対してストレージ オブジェクトを追加または削除できます。

.開始する前に
アプリケーション管理者またはストレージ管理者のロールが必要です。

.手順
. 左側のナビゲーションペインで、*ストレージ管理* ＞ *グループ*をクリックします。
. 「グループルール」タブで、編集するグループルールを選択し、「編集」をクリックします。
. 「グループルールの編集」ダイアログボックスで、必要に応じてグループルール名、関連付けられたグループ名、条件グループ、および条件を変更します。
+
[NOTE]
====
グループ ルールのターゲット オブジェクト タイプは変更できません。

====
. *保存*をクリックします。
