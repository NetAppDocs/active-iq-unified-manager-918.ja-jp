= Active IQ Unified Manager でクラスターとストレージ VM のセキュリティステータスを表示する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Managerでは、環境内のストレージ オブジェクトのセキュリティ ステータスをインターフェイスのさまざまなポイントで確認できます。定義したパラメータに基づいて情報とレポートを収集および分析し、監視対象のクラスタおよびStorage VMについて、不審な挙動や不正なシステム変更を検出することができます。

セキュリティに関する推奨事項については、以下を参照してください。 https://www.netapp.com/pdf.html?item=/media/10674-tr4569pdf.pdf["NetApp ONTAP 9 セキュリティ強化ガイド"^]



[[view-object-level-security-status-on-security-page]]
== [セキュリティ]ページでのオブジェクト レベルのセキュリティ ステータスの表示

システム管理者は、*セキュリティ*ページを使用して、データセンターおよびサイトレベルでのONTAPクラスタとストレージVMのセキュリティ強度を可視化できます。サポートされているオブジェクトは、クラスタ、ストレージVM、およびボリュームです。以下の手順に従ってください：

.手順
. 左側のナビゲーションペインで、*ダッシュボード*をクリックします。
. 監視対象のすべてのクラスタのセキュリティステータスを表示するか、単一のクラスタのセキュリティステータスを表示するかに応じて、*All Clusters* を選択するか、ドロップダウンメニューから単一のクラスタを選択してください。
. 「セキュリティ」パネルの右矢印をクリックします。[セキュリティ]ページが表示されます。


棒グラフ、カウント、および `View Reports`リンクをクリックすると、ボリューム、クラスタ、またはStorage VMsページに移動し、必要に応じて対応する詳細を表示したり、レポートを生成したりすることができます。

[セキュリティ]ページには、次のパネルが表示されます。

* *クラスタコンプライアンス*：データセンター内のすべてのクラスタのセキュリティステータス（準拠しているクラスタ数または準拠していないクラスタ数）
* *ストレージVMのコンプライアンス*：データセンター内のすべてのストレージVMのセキュリティステータス（準拠しているストレージVMの数、または準拠していないストレージVMの数）
* *ボリューム暗号化*：環境内のすべてのボリュームのボリューム暗号化ステータス（暗号化されているボリュームと暗号化されていないボリュームの数）
* *ボリュームのランサムウェア対策ステータス*：環境内のすべてのボリュームのセキュリティステータス（ランサムウェア対策が有効または無効になっているボリュームの数）
* *クラスタ認証と証明書*：SAML、Active Directory、証明書、ローカル認証など、各認証方法を使用しているクラスタの数。このパネルには、証明書の有効期限が切れている、または60日以内に有効期限が切れるクラスタの数も表示されます。




[[view-security-details-of-all-clusters-on-the-clusters-page]]
== [クラスタ]ページでのすべてのクラスタのセキュリティの詳細表示

「クラスタ／セキュリティ」の詳細ページでは、クラスタレベルでのセキュリティコンプライアンス状況を確認できます。

.手順
. 左側のナビゲーションペインで、*ストレージ > クラスタ*をクリックします。
. *表示 > セキュリティ > すべてのクラスタ*を選択します。


グローバルFIPS、Telnet、安全でないSSH設定、ログイン バナー、ネットワーク タイム プロトコル、AutoSupport HTTPS転送、クラスタの証明書の有効期限のステータスなど、デフォルトのセキュリティ パラメータが表示されます。

image:icon_kabob.gif["ケバブアイコン"] 「その他のオプション」ボタンをクリックして、Unified Managerの「セキュリティ」ページまたはSystem Managerでセキュリティの詳細を表示するように選択できます。System Managerで詳細を表示するには、有効な認証情報が必要です。


NOTE: クラスタに期限切れの証明書がある場合は、*Cluster Certificate Validity* の下にある `expired`をクリックして、System Manager（9.10.1以降）から更新できます。System Managerインスタンスのリリースが9.10.1より前の場合、 `expired`をクリックすることはできません。

== [Storage VM]ページでのすべてのクラスタのセキュリティの詳細の表示

「ストレージVM / セキュリティ」の詳細ページでは、ストレージVMレベルでのセキュリティコンプライアンス状況を確認できます。

.手順
. 左側のナビゲーションペインで、*ストレージ > ストレージVM*をクリックします。
. *表示 > セキュリティ > すべてのStorage VM*を選択します。セキュリティパラメータが設定されたクラスタの一覧が表示されます。


Storage VMのセキュリティ コンプライアンスのデフォルトのビューで、Storage VM、クラスタ、ログイン バナー、監査ログ、安全でないSSH設定などのセキュリティ パラメータを確認できます。

image:icon_kabob.gif["ケバブアイコン"] 「その他のオプション」ボタンをクリックして、Unified Managerの「セキュリティ」ページまたはSystem Managerでセキュリティの詳細を表示するように選択できます。System Managerで詳細を表示するには、有効な認証情報が必要です。

ボリュームおよびストレージVMのランサムウェア対策セキュリティの詳細については、link:../health-checker/task_view_antiransomware_status_of_all_volumes_storage_vms.html["すべてのボリュームとストレージVMのランサムウェア対策ステータスを表示する"]を参照してください。
