= Active IQ Unified Manager に表示するパフォーマンスチャートを選択する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
[グラフを選択]ドロップダウン リストを使用して、[カウンタ グラフ]ペインに表示するパフォーマンス カウンタ グラフのタイプを選択できます。パフォーマンス要件に基づいて、特定のデータやカウンタを表示できます。

.手順
. *Counter Charts* ペインで、*Choose charts* ドロップダウンリストをクリックします。
. チャートを追加または削除します。
+
|===
| 目的 | 操作 


 a| 
チャートを個別に追加または削除する
 a| 
表示または非表示にするチャートの横のチェック ボックスをオンにします。



 a| 
すべてのチャートを追加する
 a| 
「すべて選択」をクリックします。



 a| 
すべてのチャートを削除する
 a| 
「すべて選択解除」をクリックします。

|===
+
選択したグラフは、カウンターグラフペインに表示されます。グラフを追加すると、新しいグラフは「グラフの選択」ドロップダウンリストに表示されているグラフの順序に合わせて、カウンターグラフペインに挿入されます。追加のグラフを選択するには、さらにスクロールが必要になる場合があります。
