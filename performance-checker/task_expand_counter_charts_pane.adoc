= Active IQ Unified Manager でカウンターチャートペインを展開する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
カウンターチャートのペインを拡大すると、チャートが大きくなって見やすくなります。

比較対象とカウンターの時間範囲を定義したら、より大きなカウンターチャートペインを表示できます。パフォーマンスエクスプローラーウィンドウの中央にある「<」ボタンを使用して、ペインを展開します。

.手順
. 「カウンターチャート」ペインを拡大または縮小します。


|===
| 目的 | 操作 


 a| 
カウンターチャートのペインをページ幅に合わせて拡張します
 a| 
「<」ボタンをクリックします



 a| 
カウンターチャートのペインをページの右半分に縮小します。
 a| 
*>* ボタンをクリックしてください

|===
