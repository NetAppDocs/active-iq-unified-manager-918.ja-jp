= Active IQ Unified Manager のロールベースアクセス制御について
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
RBAC （ロールベースアクセス制御）は、Active IQ Unified Manager サーバのさまざまな機能やリソースへのアクセスを制御する機能を提供します。RBAC を使用すると、管理者はロールを定義することでユーザーグループを管理できます。特定の機能へのアクセスを特定の管理者のみに制限する必要がある場合は、該当する管理者用に管理者アカウントを設定する必要があります。管理者が閲覧できる情報や実行できる操作を制限する場合は、作成する管理者アカウントにロールを適用する必要があります。

管理サーバでは、ユーザ ログインとロールの権限に対してRBACを使用します。管理サーバで管理ユーザ アクセスのデフォルト設定を変更していない場合は、ログインして設定を表示する必要はありません。

特定の権限を必要とする処理を開始すると、管理サーバによってログインが求められます。たとえば、管理者アカウントを作成するには、アプリケーション管理者アカウントのアクセス権でログインする必要があります。
