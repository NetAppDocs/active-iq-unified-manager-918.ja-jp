= Active IQ Unified Manager 監査ログの設定
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
監査ログセクションの*設定*ボタンを使用すると、監査ログファイルのローリングポリシーを設定したり、監査ログのリモートログ記録を有効にしたりできます。

システムに保管したいデータの量と頻度に応じて、*最大ファイルサイズ*と*監査ログ保持日数*の値を設定できます。*監査ログ合計サイズ*フィールドの値は、システムに存在する監査ログデータの合計サイズを示します。ロールオーバーポリシーは、*監査ログ保持日数*、*最大ファイルサイズ*、および*監査ログ合計サイズ*のフィールドの値によって決定されます。監査ログのバックアップサイズが*監査ログ合計サイズ*で設定された値に達すると、最初にアーカイブされたファイルが削除されます。これは、最も古いファイルが削除されることを意味します。しかし、そのファイルエントリはデータベース内に残っており、「`Rollover Delete`」とマークされます。*監査ログ保持日数*の値は、監査ログファイルが保持される日数を表します。このフィールドに設定された値よりも古いファイルはすべてロールオーバーされます。

.手順
. *監査ログ* > > *設定* をクリックします。
. *最大ファイルサイズ*、*監査ログの合計サイズ*、および*監査ログの保持日数*に値を入力してください。
+
リモートログを有効にするには、*リモートログを有効にする*を選択します。
