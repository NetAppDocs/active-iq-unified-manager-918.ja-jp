= Active IQ Unified Manager で監査ログのリモートロギングを有効にする
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
リモート監査ログを有効にするには、「監査ログの設定」ダイアログボックスで「リモートログを有効にする」チェックボックスを選択します。この機能を使用すると、監査ログをリモートSyslogサーバに転送できます。これにより、容量に制約がある場合でも監査ログを管理できるようになります。

監査ログのリモート ロギングは、Active IQ Unified Managerサーバ上の監査ログ ファイルが改ざんされた場合のバックアップとしても機能します。

.手順
. 「監査ログの設定」ダイアログボックスで、「リモートログを有効にする」チェックボックスを選択します。
+
リモート ロギングを設定するためのフィールドが表示されます。

. 接続するリモート サーバの*HOSTNAME*と*PORT*を入力します。
. *サーバーCA証明書*フィールドで、*参照*をクリックして、対象サーバーの公開証明書を選択します。
+
証明書は `.pem`形式でアップロードする必要があります。この証明書は対象のSyslogサーバから取得する必要があり、有効期限が切れていないものでなければなりません。証明書には、選択した「`hostname`」が `SubjectAltName`（SAN）属性の一部として含まれている必要があります。

. 以下のフィールドに値を入力してください：*CHARSET*、*CONNECTION TIMEOUT*、*RECONNECTION DELAY*。
+
ミリ秒単位の値を指定してください。

. *FORMAT* および *PROTOCOL* フィールドで、必要なSyslogフォーマットとTLSプロトコル バージョンを選択します。
. 対象のSyslogサーバが証明書ベースの認証を必要とする場合は、*クライアント認証を有効にする*チェックボックスを選択します。
+
監査ログ設定を保存する前に、クライアント認証証明書をダウンロードしてsyslogサーバにアップロードする必要があります。そうしないと、接続が失敗します。syslogサーバのタイプによっては、クライアント認証証明書のハッシュを作成する必要があります。

+
例：syslog-ng では、コマンド `openssl x509 -noout -hash -in cert.pem`を使用して証明書の<hash>を作成する必要があります。その後、クライアント認証証明書を<hash> .0 という名前のファイルにシンボリック リンクする必要があります。

. *Save*をクリックしてサーバとの接続を設定し、リモートログ記録を有効にします。
+
[監査ログ]ページにリダイレクトされます。

+
[NOTE]
====
*接続タイムアウト*の値は設定に影響を与える可能性があります。設定応答時間が規定値よりも長くなると、接続エラーにより設定が失敗する可能性があります。接続を正常に確立するには、*接続タイムアウト*の値を増やして、再度設定を試してください。
