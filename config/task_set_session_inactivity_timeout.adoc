= Active IQ Unified Manager でセッションの非アクティブタイムアウトを設定する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Managerの非アクティブタイムアウト値を指定することで、一定期間操作がないとセッションが自動的に終了するように設定できます。デフォルトでは、タイムアウトは4,320分（72時間）に設定されています。

.開始する前に
アプリケーション管理者のロールが必要です。

この設定は、ログインしているすべてのユーザ セッションに適用されます。

[NOTE]
====
このオプションは、Security Assertion Markup Language（SAML）認証を有効にしている場合は使用できません。

====
.手順
. 左側のナビゲーションペインで、*General* > *Feature Settings* をクリックします。
. *機能設定*ページで、以下のいずれかのオプションを選択して、非アクティブタイムアウトを指定します。
+
[cols="2*"]
|===
| 状況 | 操作 


 a| 
タイムアウトを設定しない（セッションを自動的に閉じない）
 a| 
「非アクティブタイムアウト」パネルで、スライダーボタンを左（オフ）に移動して、「適用」をクリックします。



 a| 
タイムアウト値（分）を設定する
 a| 
「非アクティブタイムアウト」パネルで、スライダーボタンを右（オン）に移動し、非アクティブタイムアウト値を分単位で指定して、「適用」をクリックします。

|===
