= Active IQ Unified Manager のメンテナンスユーザーについて
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified ManagerをRed Hat Enterprise Linuxシステムにインストールする場合、インストール時にメンテナンス ユーザが作成されます。メンテナンス用ユーザー名は「`umadmin`」ユーザーです。メンテナンスユーザーはWeb UIでアプリケーション管理者ロールを持ち、そのユーザーは後続のユーザーを作成してロールを割り当てることができます。

メンテナンス ユーザまたはumadminユーザは、Unified Managerのメンテナンス コンソールにもアクセスできます。
