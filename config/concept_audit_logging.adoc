= Active IQ Unified Manager の監査ログについて
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
監査ログを使用することで、監査ログが侵害されているかどうかを検出できます。ユーザーが実行したすべてのアクティビティは監視され、監査ログに記録されます。監査は、Active IQ Unified Managerのすべてのユーザーインターフェイスおよび公開されているAPIの機能に対して実行されます。

*監査ログ：ファイルビュー*を使用すると、Active IQ Unified Managerで使用可能なすべての監査ログファイルを表示およびアクセスできます。監査ログ：ファイルビューでは、ファイルは作成日順に一覧表示されます。このビューには、システムへのインストールまたはアップグレードから現在までに取得されたすべての監査ログの情報が表示されます。Unified Managerで何らかの操作を行うと、その情報が更新され、ログに記録されます。各ログファイルの状態は、「\`File Integrity Status\`」属性を使用して取得され、ログファイルの改ざんや削除を検出するために積極的に監視されます。監査ログがシステム内で利用可能な場合、監査ログは次のいずれかの状態になります：

[cols="2*"]
|===
| 状態 | 説明 


 a| 
ACTIVE
 a| 
ログを記録中のファイル。



 a| 
NORMAL
 a| 
圧縮されてシステムに格納されている、アクティブでないファイル。



 a| 
TAMPERED
 a| 
侵害されたファイル（権限のないユーザによって手動で編集された）。



 a| 
MANUALL_DELETE
 a| 
権限のあるユーザによって削除されたファイル。



 a| 
ROLLOVER_DELETE
 a| 
ローリング設定ポリシーに基づいてロールオフで削除されたファイル。



 a| 
UNEXPECTED_DELETE
 a| 
不明な理由で削除されたファイル。

|===
[監査ログ]ページには、次のコマンド ボタンがあります。

* 設定
* 削除
* ダウンロード


*DELETE*ボタンを使用すると、Audit Logsビューに表示されている任意の監査ログを削除できます。監査ログを削除する際、必要に応じてファイルの削除理由を指定できます。これは、将来的に正当な削除であるかを判断するのに役立ちます。REASON列には、削除操作を実行したユーザー名とともに、その理由が表示されます。

[NOTE]
====
ログ ファイルを削除すると、システムからファイルが削除されますが、DBテーブル内のエントリは削除されません。

====
Active IQ Unified Managerの監査ログセクションにある*DOWNLOAD*ボタンを使用して監査ログをダウンロードし、監査ログファイルをエクスポートできます。「`NORMAL`」または「`TAMPERED`」とマークされたファイルは、圧縮 `.gzip`形式でダウンロードされます。

監査ログ ファイルは定期的にアーカイブされ、参照できるようにデータベースに保存されます。セキュリティと整合性を維持するために、アーカイブ前に監査ログはデジタル署名されます。

完全なAutoSupportバンドルには、アーカイブされた監査ログ ファイルとアクティブな監査ログ ファイルの両方が含まれます。一方、軽量なサポート バンドルには、アクティブな監査ログのみが含まれます。アーカイブされた監査ログは含まれません。
