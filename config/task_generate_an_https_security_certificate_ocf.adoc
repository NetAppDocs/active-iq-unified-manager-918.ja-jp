= Active IQ Unified Manager でHTTPSセキュリティ証明書を生成する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Managerを初めてインストールすると、デフォルトのHTTPS証明書がインストールされます。新しいHTTPSセキュリティ証明書を生成して、既存の証明書を置き換えることができます。

.開始する前に
アプリケーション管理者のロールが必要です。

証明書を再生成する理由はいくつもあります。たとえば、識別名（DN）をより適切な値に変更する場合、キーのサイズを大きくする場合、有効期限を延長する場合、現在の証明書の有効期限が切れた場合などです。

Unified Manager Web UI にアクセスできない場合は、メンテナンス コンソールを使用して同じ値で HTTPS 証明書を再生成できます。証明書を再生成する際に、鍵のサイズと鍵の有効期間を指定できます。メンテナンス コンソールの `Reset Server Certificate`オプションを使用すると、397日間有効な新しいHTTPS証明書が作成されます。この証明書には、2048ビットのRSA鍵が含まれます。

.手順
. 左側のナビゲーションペインで、*General* > *HTTPS Certificate* をクリックします。
. *HTTPS証明書を再生成*をクリックします。
+
[HTTPS証明書の再生成]ダイアログ ボックスが表示されます。

. 証明書を生成する方法に応じて、次のいずれかを実行します。
+
[cols="2*"]
|===
| 状況 | 操作 


 a| 
現在の値で証明書を再生成する
 a| 
「現在の証明書属性を使用して再生成」オプションをクリックします。



 a| 
別の値で証明書を生成する
 a| 
*現在の証明書の属性を更新する*オプションをクリックします。

「共通名」と「代替名」のフィールドに新しい値を入力しない場合、既存の証明書の値が使用されます。「`Common Name`」には、ホストのFQDNを設定する必要があります。その他のフィールドには値を入力する必要はありませんが、証明書に値を反映させたい場合は、たとえばEMAIL、COMPANY、DEPARTMENT、City、State、Countryなどのフィールドに値を入力できます。利用可能な鍵サイズ（鍵アルゴリズムは「`RSA`」です）と有効期間を選択することもできます。

[NOTE]
====
** キーサイズの許容値は `2048`、 `3072`、および `4096`です。
** 有効期間は1日～36500日です。
+
ただし、推奨される有効期間は397日（13カ月）以内です。397日を超える有効期間を選択しても、CSRをエクスポートして既知のCAから署名を受ける場合にCAからは有効期間が397日に削減され署名済み証明書が返されます。

** 証明書の[別名]フィールドにローカルの識別情報を含めない場合は、[ローカルの識別情報を除外する（ローカルホストなど）]チェックボックスを選択します。このチェックボックスを選択すると、このフィールドで入力した情報だけが[別名]フィールドで使用されます。このフィールドを空白にした場合は、[別名]フィールドのない証明書が生成されます。


====
|===
. 証明書を再生成するには、「はい」をクリックします。
. 新しい証明書を有効にするためにUnified Managerサーバを再起動します。
. HTTPS証明書を表示して新しい証明書の情報を確認します。
