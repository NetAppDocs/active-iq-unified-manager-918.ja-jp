= Active IQ Unified Manager にログインバナーを追加する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ログイン バナーを追加して、システムへのアクセスを許可されているユーザや利用条件などの情報をログインとログアウトの際に表示することができます。

このログイン バナーのポップアップは、ストレージのオペレータや管理者などのすべてのユーザに対して、ログイン、ログアウト、セッション タイムアウトの際に表示されます。
