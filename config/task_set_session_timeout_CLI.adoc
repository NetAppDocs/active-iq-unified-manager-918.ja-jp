= Active IQ Unified Manager でCLIを使用してセッションタイムアウトを設定する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
CLIを使用してUnified Managerのセッションタイムアウトの最大値を設定することで、一定時間経過後にセッションを自動的に終了させることができます。デフォルトでは、セッションタイムアウトは最大値である4,320分（72時間）に設定されています。これは、ログインしてUnified Managerをアクティブに使用している場合でも、72時間後にセッションが自動的に終了することを意味します。

.タスク概要
アプリケーション管理者のロールが必要です。

セッションタイムアウト設定は、ログインしているすべてのユーザーセッションに影響します。

.手順
. Unified Manager CLIにログインするには、 `um cli login` コマンドを入力します。認証には有効なユーザ名とパスワードを使用してください。
. セッションタイムアウト値を変更するには、 `um option set max.session.timeout.value=<in mins>` コマンドを入力します。
